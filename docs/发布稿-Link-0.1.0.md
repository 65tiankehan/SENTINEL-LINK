# 【SPT4.1.6】SENTINEL LINK —— 好友、私聊、世界频道，长在游戏原本的聊天窗里

> 标签：`#4.1.6` `#联机` `#社交` `#单人可用`

先说不绕的：**SENTINEL LINK 不是联机开黑模组**。

它解决的是另一件事 —— 单机 SPT 里，你和别的服、别的人之间没有任何通道。你只能对着自己的存档说话。
LINK 干的就是这条通道：把「人」接进游戏**原本的好友列表和聊天窗**，不做第二套界面，不劝你换掉原来的习惯。

一条 Hub 在中间转消息，你自己的服还在自己电脑上跑，存档还在你手里。

---

## 一、装完你会多出什么

### 1. 好友：别人会真的出现在你的好友列表里

不是另开一个窗口，是游戏原来那个「好友列表」。对方的昵称、等级、阵营都是真数据。
你点开他，就是一个正常的私聊对话 —— 你可以发消息，他那边收得到。

- **不同服的人也能互相加好友**（各自 SPT 服务端连同一个 Hub，realm 相同即可）
- 好友来自「在线对端 ∪ 跟你聊过的人」，所以对方下线了、对话不会消失
- 好友列表里还会多三个固定频道：`世界` / `交易` / `求组`

### 2. 私聊：离线也不丢

对方在挂机、在吃饭、或者压根没开游戏，你照发。消息进 Hub 的落盘队列（每人 500 条、保留 168 小时），
他一上线，先补投再聊天，顺序不乱。

实测口径：给一个离线账号连发 100 条 → 上线实收 100 条、`dm-sync` 1 次、队列清空，对账 0 丢失。

### 3. 世界 / 交易 / 求组：三个频道，就在原生聊天窗

这三个频道是转发型的公共频道（Hub 每个频道存最近 100 条给你补历史）。
发出去的消息，同一 realm 里所有人都能看到，不用互相加好友。

- 输入框就是游戏自己的输入框，格式校验也放开了，能打中文
- 局内没有聊天入口 —— 这点和原版一样，所以局内用下面的面板

### 4. 一个面板：F11

**F11**（或 `Ctrl+L`）开合，主菜单、藏身处、局内都能用。

- 面板一开，人物的移动、视角、开火就被锁住（不会被鼠标带偏、不会走火），关掉立刻恢复
- 中文输入：面板里用 `Ctrl+V` 粘贴（`IME` 已经打开，输入法浮窗行为看你的系统）
- `回车` 发送、`Esc` 关闭、滚轮翻历史

## 二、它是怎么接进去的（给想知道原理的人）

| 环节 | 做法 |
| --- | --- |
| 好友 | 服务端在 `GetFriendList` 的返回值里追加对端，**不写 `FriendProfileIds`** |
| 对话列表 | 在 `GenerateDialogueList` 尾部追加虚拟会话 |
| 打开对话 | `GenerateDialogueView` 前缀拦截虚拟 id，直接用内存里的历史拼返回 |
| 发消息 | `SendMessage` 前缀拦下（虚拟 id），转给 Hub；**不走原生的写档路径** |
| 频道 | 三个频道同样走原生对话，消息类型用 `UserMessage`（和私聊同一契约，客户端才肯渲染） |
| 存档 | 虚拟 id 一律 `sha256(...) 前 20 位 + 1e0f` 域标记；实测发消息前后 profile **字节级不变**，文件里搜不到任何虚拟 id |

也就是说：**它不改你的存档，不改游戏文件**，只是让原生界面多画几行、多发几帧。

代价是它得靠 Harmony 补丁挂在几处原生方法上，SPT 大版本更新后可能失效 —— 所以补丁是**逐条可降级**的：
哪条挂不上就只记日志、退回面板，不会崩游戏。

## 三、安装：三步，没有广告

1. 下载 `SENTINEL-LINK-Setup.exe`，双击，选游戏根目录（含 `EscapeFromTarkov.exe` 那层）
2. 装完**重启游戏**；主菜单底栏「消息」里就能看到好友和世界频道
3. 要联机时，先跑游戏目录里的 `SENTINEL-Link-Hub\启动 Hub.cmd`

安装器会一次装好三样东西：

```
BepInEx\plugins\SENTINEL.Link\                            客户端插件
SPT_Runtime\user\mods\cn.passionyang.sentinellink.server\  服务端模组 + config.json
SENTINEL-Link-Hub\                                         本地 Hub（双击启动）
```

**Hub 需要 .NET 10 运行时**（有 `dotnet` 命令就行；`启动 Hub.cmd` 会先检查，缺了给你下载地址）。
默认监听 `http://127.0.0.1:5180`，自己要开放给朋友就连 `0.0.0.0`，端口和邀请码用环境变量改：

```powershell
$env:SENTINEL_HUB_PORT = "5180"      # 端口
$env:SENTINEL_HUB_KEY  = "换成你的"   # 邀请码（对端 hello 必须一致）
$env:SENTINEL_HUB_REALM= "default"   # 同一个 realm 才互相看见
dotnet SENTINEL.Link.Hub.dll
```

连别人的服：改自己这边的
`SPT_Runtime\user\mods\cn.passionyang.sentinellink.server\config.json` 里的 `hubUrl` / `inviteKey` / `realm`。

## 四、它不做什么（写清楚，省得误会）

- **不联机开黑**：组队跨局（P5）还在规划，那条路要接 Fika，不是这个版本的事
- **不碰跳蚤市场**：跨服报价（P3）没做完，装了也不会有
- **不装也能玩**：Hub 没起来时，好友与世界频道是空的，其他功能一切照常
- **不收集数据**：没有遥测、没有账号系统、没有云端；消息只在你和 Hub 之间走
- **不改存档**：上面那节写了，虚拟 id 不进 profile

## 已知限制

- 世界频道没有未读红点分层，三个频道和私聊共用原来那套计数
- 好友列表的「好友 (N)」计数目前把三个频道也算进去
- 同机双开游戏仍然不行（游戏自己挡着），要测双人得两台机器
- Hub 是单点内存态：私聊队列写盘不丢，**世界频道的历史重启就没了**（只保最近 100 条）
- 好友栏里有些条目点开是空的（对方离线且没聊过），属正常
